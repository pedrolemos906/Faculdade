# Desenvolvimento Web Back-End

## Conteúdos da disciplina

- 1. Aspectos da arquitetura Web.
    - Apresentação e nivelamento.
    - Evolução das Aplicações Web.
    - Fluxo de Arquitetura Web.
    - Cookies, Sessões, StatusCode, Headers e Métodos Header.
    - Arquitetura Cliente, Servidor e MVC.

- 2. Plataformas Web para Front-End e Back-End (Frameworks).
    - Frameworks Web.
    - Back-End Express JS, Node JS  e Vite.

- 3. Uso de API e Web Service.
    - Conceito de API e Web Service.
    - Endpoints, consumo de API e serialização.
    - SPA e Mockups

- 4. Acesso a Banco de Dados.
    -Integração com Banco de Dados.
    -Consultas, paginação, ordenação e filtros.
